# Attribution

Custom macro compatibility was designed from the documented syntax and behavior of [killburne/custom-duelingbook](https://github.com/killburne/custom-duelingbook), whose userscript metadata declares the MIT License.

YugiFaux Companion independently wraps the compatible macro names in a strict parser and action allowlist. The reference project's function names, variable names, zone notation, and DuelingBook play mappings are retained so existing player macro definitions can be imported with minimal changes.
